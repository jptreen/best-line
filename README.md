# Best Line

A dice probability puzzle. You're shown a grid of mixed dice — d4 through
d20 — each showing a random roll. Pick the row, column or diagonal most
likely to come up all-matching if you re-rolled it. Dice already showing
the target number are kept; only the mismatched ones re-roll.

Twelve rounds, getting harder: the die pool widens at round 5, the board
grows from 4×4 to 5×5 at round 9, and d4 and d20 arrive at round 11.

**Play it: https://jptreen.github.io/best-line/**

One file, no dependencies — open `index.html` in any browser.
